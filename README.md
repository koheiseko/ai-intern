# AI Intern

AI Intern é um projeto em desenvolvimento para criar um agente de IA capaz de realizar pesquisa automatizada em machine learning (ML).

A proposta é automatizar o ciclo de pesquisa: formular hipóteses, implementar e executar experimentos, avaliar resultados e propor melhorias a partir das evidências obtidas.

O projeto se inspira em iniciativas como autoresearch, AI Scientist, Darwin Gödel Machine e AlphaEvolve, com o objetivo de explorar como agentes podem contribuir para a descoberta e o aprimoramento de métodos de ML.
